MERCADO SOUZA — SITE COM PAINEL E BANCO CONECTADO

O projeto Mercado Souza foi criado no seu Supabase, na região de São Paulo.
As tabelas, permissões, espaço para fotos e 45 produtos já foram configurados.
O arquivo config.js já está preenchido somente com a conexão pública.

PRÓXIMOS PASSOS
1. Abrir COMECE-AQUI.html e seguir o passo 3 para criar/liberar o login do dono.
2. Abrir esta pasta no VS Code e atualizar os arquivos do repositório GitHub do site.
3. Publicar pelo projeto Vercel existente. Não é preciso instalar pacotes nem compilar.

Abra admin.html e escolha a demonstração para conhecer o painel.
A demonstração não salva dados. O acesso real exige usuário autorizado.

Mantenha a pasta assets ao enviar o projeto.
Artes antigas podem ter preços desenhados; substitua a arte quando mudar esse preço.
